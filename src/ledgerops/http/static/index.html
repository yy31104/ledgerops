Controlled reprocessing: propose → separate review → execute
Available only on the separate operator instance. Reprocesses repaired LOCAL_BLOCKER cases with existing terminal observations; it cannot release UNKNOWN holds, override contradictions or edit amounts directly. The server checks current permissions and evidence at every step.


1. Propose an action
Find the terminal observation and current reconciliation run in the operation investigation first. Submit references only; the server captures amounts, the complete incident set and target versions. Proposals expire after 15 minutes.




2. Load and review the proposal
Connect with a different reviewer's credential, then load the proposal ID. Check the amount, merchant, payment key, evidence version, incidents and expiry. The review below corresponds to the exact proposal bytes; the browser recomputes SHA-256. Both the database and service reject self-approval.

3. Execute and inspect the retained result
