## Boundaries and next work

The maintenance credential can directly write projections/metadata and therefore
must follow the Python/barrier protocol. UUID labels are not authentication. A DB
owner can change guards; raw SQL that ignores advisory locks is outside writer-drain
claims. Database freeze does not establish that external payment execution stopped.

Preview ID is a caller-declared audit reference; no claim is made that a file was
authenticated or a human read it. Apply accepts no target balances and reads no
preview file. Post-export is a separate inspectable workflow step; resume performs
fresh live checks, not a stale-file approval gate. Historical replay returns retained
metadata without asserting the workspace's current state.

Reports preserve PR01's retained-request/opaque OPENING/reservation limits. Export
size/row caps remain bounded. Format-v1 interpretation remains the old contract;
it does not retroactively gain v2 maintenance evidence. No filesystem hardening
beyond PR01's existing protections was added.

R2-PR03 production reversal and PR04 integrated acceptance remain. No persistent
demo DB, HTTP/token adapter, push, tracker or Chronicle edit. Yi's decisions were
accepted; independent personal mastery remains unassessed.
