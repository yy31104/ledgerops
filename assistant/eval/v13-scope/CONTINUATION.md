# Scope study continuation

The first three comparisons used the [original protocol](protocol.json).
Round 3 met the documentation and retrieval targets and missed the unsupported
admission target. Its result remains part of the study.

Round 4 and any later comparison use the same targets, population requirements,
reference, calibration cutoff rule, and intervals. Each comparison uses a new
source-only cohort audited by separate contexts as described in
[the review method](REVIEW-METHOD.md). Freeze and push the candidate and cohort
before the single attempt. Keep results from every attempt, including misses.

Use previously completed failed comparisons as development evidence. Check the
next rule on those cohorts and record the evidence for the change before scoring
the next holdout. Stop when one comparison meets all three targets. Keep each
round's score and intervals separate because question populations vary.
