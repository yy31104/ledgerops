## 生产标准如何验收

1. **身份与权限**：服务身份由验证后的凭据映射，禁止任意请求 UUID 自授角色；跨 workspace、
   重放读取、商户提现、maker/checker 同人、撤销身份和旧审批均有负向测试。
   生产模式不能回退到合成测试身份；测试密钥、默认密码、故障控制面不能在生产配置下启动。
2. **金融完整性**：已有 R1/R2 不变量继续成立；R3 支付事实/hold/资金变更原子，
   R4 不自动修正差异；人工操作只能走类型化、版本绑定、幂等且审计的业务入口。
3. **资源与并发**：HTTP 请求/正文/队列/数据库连接和工作循环有明确上限；
   取消/超时/断线后释放连接；真正的幂等并发和数据库等待测试，不能用内存 mock 代替。
4. **可运维性**：区分存活、数据库就绪和外部积压；输出不泄露密钥的 request/operation/event 关联；
   UNKNOWN 年龄、失败尝试、隔离/矛盾和重试耗尽可查询。成功响应不是唯一监控指标。
5. **迁移与恢复**：新数据库和升级数据库都演练；历史迁移/导出仍可验证；备份包含所需指令、
   身份、密钥引用和外部证据。恢复模式默认禁止派发，provider 领先或历史缺失时明确阻塞。
6. **交付**：锁定依赖和镜像配置、非 root 运行、敏感配置外置；干净环境可以启动与验证。
   每个完成项有实际测试命令、版本、提交和失败边界；不把测试数量替代场景覆盖。
